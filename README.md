## Installation & Usage

### 1. Oh My Pi (OMP)
Copy or symlink the agents and skills into your local OMP configuration directory:
```bash
# Clone this repository
git clone https://github.com/fikrimastor/skills.git ~/omp-skills

# Sync Subagents
mkdir -p ~/.omp/agents
cp -r ~/omp-skills/agents/* ~/.omp/agents/

# Sync Skills
mkdir -p ~/.omp/skills
cp -r ~/omp-skills/skills/* ~/.omp/skills/

# Copy Orchestrator Rules (optional / project-level)
cp ~/omp-skills/AGENTS.md ~/.omp/AGENTS.md
```

### 2. Claude Code & Agent Skills
Skills follow standard agent skills directory format (`<skill-name>/SKILL.md`). You can vendor individual skills into `~/.claude/skills/` or your project root `.claude/skills/`:

```bash
mkdir -p ~/.claude/skills
cp -r ~/omp-skills/skills/<skill-name> ~/.claude/skills/
```
