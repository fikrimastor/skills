# repowiki-sync — keeping `docs/architecture` current

The narrative architecture wiki for the five Tricipta repos lives in the **workspace repo**
(`afed/tricipta/docs/architecture/<repo>/`), generated by `scripts/repowiki.py` from the frozen Qoder
exports (briefs + policy) with **no Qoder service involved**. The five product repos are *siblings* of
the workspace (`../tricipta-edafy-asset-api`, …), not children.

Run everything from the workspace root: `cd ~/Sites/afed/tricipta`.

## The loop

```bash
python3 scripts/repowiki.py check                    # 1. what is stale? (gate; see exit codes)
python3 scripts/repowiki.py generate --dry-run       # 2. what would a run cost? (calls nothing)
python3 scripts/repowiki.py generate --repo asset-api --page "Well Management"   # 3. regenerate
python3 scripts/repowiki.py check                    # 4. verify; repeat for any flagged page
git add docs/architecture && git commit -m "docs(repowiki): sync <repo> to <sha>"
```

`check` per repo reports: pages present/scoped, dead citations, out-of-bounds line anchors, the **oldest
page anchor** (worst-case lag in commits), the **stale page list** (pages whose cited files changed since
*that page's* anchor), and **integrity flags**. Work the stale list; prefer `--page` over whole-repo
runs.

**Exit codes** — `0` clean · `1` drift or integrity flags past threshold · `2` nothing to check (run
`generate` first). Never treat a message-free run as a pass.

## Models

Configured in `afed/tricipta/.env` (gitignored) — **never** read a sibling repo's `.env`; asset-api's
holds the product's Databricks serving credentials and is deliberately ignored.

```
DEEPSEEK_API_KEY=<paste from platform.deepseek.com/api_keys>   # placeholder values are rejected
LLM_MODEL=deepseek-v4-pro        # or deepseek-flash (cheaper; ~69–85% of the length)
```

Only `deepseek-flash` and `deepseek-v4-pro` exist. Thinking is **off by default here**
(`reasoning_effort: "none"`) because reasoning tokens bill as output and eat the budget; `--effort
low|high|max` turns it on. Verify the key before a long run with `python3 scripts/repowiki.py models`.
Cost for all 85 pages, thinking off: flash ≈ $0.66 off-peak / $1.32 peak; v4-pro ≈ $2.61 / $5.22
(peak = 01:00–04:00 & 06:00–10:00 UTC Mon–Fri).

## What the generator guarantees

- **Per-page anchors.** Each page records the commit its content came from; `generate` advances only the
  pages it rewrote. Never advance anchors wholesale — a partial run must leave untouched pages stale.
- **Per-page output budget** `max(2 × replaced page, 8192)`, up to 384K — nothing truncates; a page is
  written (and its anchor advanced) only on `finish_reason == "stop"`.
- **Line-numbered source** is embedded and every `#L<start>-L<end>` is validated. Past-EOF ranges are
  **degraded to a file cite, never clamped** (clamping invents precision the model never verified).
  Basename-only cites (`ci.yml`) resolve against the prompt's file list.
- **Three integrity audits** at write time, recorded in the page header and surfaced by `check`
  (`--max-flagged`, default 0): *unverified code blocks* (a fenced source-language block whose lines are
  mostly absent from the cited files), *invented paths* (a path/filename in a tree or file list that
  exists nowhere in the repo; "there is no X" is exempt), *partial grounding* (`sources n/m`, n < m).
- A page that emits **no** line anchors is retried once with a nudge.
- One H1 per page; H1 demotion is fence-aware so quoted `#` comments and shebangs survive.

## Traps

- **Verify against the file in the page's `source_files`**, never a path mentioned in the page's prose —
  two files can share a basename (`domain/capabilities.yaml` vs `plotting_core/domain/capabilities.yaml`)
  and only one is the cited source. This caused a wrong "hallucination" diagnosis once.
- **Don't regenerate a repo to fix one page** — `--page <substring>` takes seconds. Measured: a week of
  churn touches ~64 % of asset-api's pages, five weeks ~73 %.
- **`--budget-chars` (default 400 k)** caps per-page source; pages that cannot fit every cited file are
  flagged, not silently thinned. Raise it and re-run that page alone.
- **graft/graphify are not substitutes** — they are index-grade and agent-facing (`graft build`,
  `graphify export wiki`). Use them to ground pages, never to write them.
- Glossary sections are **policy-driven**: asset-api's `wiki_plan` demands `## Glossary`, other repos'
  do not.
